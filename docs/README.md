## 文档怎样维护

README 负责项目用途、核心能力和可直接执行的 Quick Start；ARCHITECTURE 负责核心架构、模块分工、处理流程和关键技术选择；本目录保存操作步骤和详细规则。同一项配置、阈值或算法只在一个地方完整说明，其他文档用链接引用。

改代码时检查受影响的文档，尤其是命令、环境变量、接口字段、限制和错误提示。已经实现的功能和后续设想要分别说明；不要把演示内容、初始项目示例或配置项的存在写成已接通的功能。

文档改动提交前检查本地链接和差异。代码同时有改动时，按[测试与验证](testing.md)完成必要检查，再按 [AGENTS.md](../AGENTS.md)提交并推送。
