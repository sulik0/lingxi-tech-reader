# 灵析 · 科技信息去噪

灵析是个人 AI 科技信息流：合并科技订阅里的重复报道，展示聚合摘要，用自然语言调整信息偏好，并查看机器人推送状态。需要深入了解时，再打开原文链接。

## 核心能力

- 按原文发布时间浏览已分析资讯，展开来源与依据，收藏保存在当前浏览器。
- 自然语言解析为关键词策略，展示变更后确认保存；支持“减少类似内容”反馈，不因改偏好重新采集。
- 比较正文，整理事实、观点、新增信息和需要保留的疑问。
- 资讯提供来源链接；原始正文、阅读记录和管理表单不占用首页。
- 将保存的当前报告推送飞书，成功后不重复发送。
- 后台持续收集，并按设定时间通过飞书、企业微信或邮件发送每日简报。

当前检索通过 RSS/Atom 完成，未接入全网搜索，也不会读取微信关注列表。真实分析需要模型凭据；应用比较来源正文，不进行外部事实核查。

## Quick Start

需要 Node.js 24、Git，以及此私人仓库的访问权限：

```sh
git clone https://github.com/sulik0/lingxi-tech-reader.git
cd lingxi-tech-reader
npm run install:ci
cp .env.example .dev.vars
npm run db:migrate
npm run dev
```

编辑隐藏文件 `.dev.vars`，填写管理口令、模型密钥和发送渠道配置；已有文件时不要重复复制覆盖。打开终端提示的本地地址，输入管理口令连接，浏览已分析资讯。首次使用时打开“设置 → 订阅来源”添加来源，再到“报告与服务”点击“检查新资讯并分析”。详细步骤见[自动订阅与推送](docs/automation.md)。本地服务不会自己定时运行。
