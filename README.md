# 灵析 · 科技信息去噪

灵析帮助读者整理科技公众号文章。多篇文章报道同一件事时，它比较各篇提供的信息、事实依据和作者观点，再给出综合简报和阅读建议，帮助你决定是否还要打开原文。

## 核心能力

- 手动导入正文，阻止相同正文重复导入，并按标题相似度初步分组。
- 连接 LLM（大语言模型）后，提取事件摘要、事实原句和作者观点，整理多篇文章的有效信息。
- 比较信息密度、原创度、事实性和分析深度，识别重复内容和夸张表述，推荐综合分最高的一篇。
- 搜索、筛选、收藏和记录已读事件；在当前浏览器保存阅读空间，导出 JSON 数据或 Markdown 简报。

内置内容均为虚构演示。不配置模型也能浏览演示和导入文章；真实文章的分析需要模型服务。公众号自动采集、外部事实查证和跨设备同步尚未实现。

## Quick Start

先安装 Node.js 24 和 Git，并确保你的 GitHub 账号有权访问此私人仓库。在终端执行：

```sh
git clone https://github.com/sulik0/lingxi-tech-reader.git
cd lingxi-tech-reader
npm run install:ci
npm run dev
```

打开 [本地工作台](http://localhost:5173)。如终端提示了其他地址，以终端输出为准。要分析自己的文章，按[模型配置说明](docs/configuration.md)设置服务后，在导入事件中点击“交叉分析”。
