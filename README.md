# 灵析 · 科技信息去噪

灵析自动收集公开科技订阅，把讨论同一件事的文章放在一起，比较正文证据、作者观点、重复内容和新增信息。你可以直接阅读整理后的事件，必要时打开推荐原文，并通过邮件、企业微信或飞书接收每日简报。

## 核心能力

- 定期读取 RSS/Atom，记录每个来源的成功或失败，避免重复入库。
- 用模型根据标题、时间和正文分组，生成事件摘要、事实依据、观点对照和逐篇评价。
- 说明每篇文章多提供了什么信息，标记重复与夸张，给出具体的阅读理由。
- 阅读工作台与每日简报使用同一份后台事件分析；支持修正分组并清除旧分析。
- 按北京时间发送每日事件简报，保留发送结果，处理迟到文章和积压文章。

演示内容均为虚构，默认隐藏。真实分析需要模型凭据；持续采集和推送需要部署后台并配置渠道。应用比较文章正文，不进行外部事实核查，也不会直接读取微信关注列表。

## Quick Start

需要 Node.js 24、Git，以及此私人仓库的访问权限：

```sh
git clone https://github.com/sulik0/lingxi-tech-reader.git
cd lingxi-tech-reader
npm run install:ci
cp .env.example .dev.vars
npm run db:migrate
npm run dev
```

编辑隐藏文件 `.dev.vars`，填写管理口令、模型密钥和发送渠道配置；已有文件时不要重复复制覆盖。打开终端提示的本地地址，在订阅管理中添加来源，再在自动阅读工作台输入口令查看事件。详细步骤见[自动订阅与推送](docs/automation.md)。本地服务不会自己定时运行。
