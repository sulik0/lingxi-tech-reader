# 灵析 · 科技信息去噪

灵析检索已配置的科技订阅，合并围绕同一事件的重复报道，生成带事实、观点和原文链接的聚合报告。先读报告，需要深入了解时再打开原文，也可以立即推送这份报告到飞书。

## 核心能力

- 一次点击完成检索、去重和报告生成，显示处理进度。
- 比较正文，整理事实、观点、新增信息和需要保留的疑问。
- 报告提供推荐原文及其他来源链接，首页不展示文章库、收藏和阅读记录。
- 将保存的当前报告推送飞书，成功后不重复发送。
- 后台持续收集，并按设定时间通过飞书、企业微信或邮件发送每日简报。

当前检索通过 RSS/Atom 完成，未接入全网搜索，也不会读取微信关注列表。真实分析需要模型凭据；应用比较来源正文，不进行外部事实核查。

## Quick Start

需要 Node.js 24、Git，以及此私人仓库的访问权限：

```sh
git clone https://github.com/sulik0/lingxi-tech-reader.git
cd lingxi-tech-reader
npm run install:ci
cp .env.example .dev.vars
npm run db:migrate
npm run dev
```

编辑隐藏文件 `.dev.vars`，填写管理口令、模型密钥和发送渠道配置；已有文件时不要重复复制覆盖。打开终端提示的本地地址，输入管理口令连接后，点击“检索并生成报告”，阅读结果后点击“推送这份报告到飞书”。右上角“设置”维护来源和每日自动推送。详细步骤见[自动订阅与推送](docs/automation.md)。本地服务不会自己定时运行。
